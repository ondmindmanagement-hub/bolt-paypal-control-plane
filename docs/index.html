Governed AI-assisted payment workflows for the PayPal Sandbox.

Architecture
Natural-language intent → local AI planner (Ollama / Qwen 2.5) → structured PayPal action → deterministic BOLT policy gate → human approval when required → PayPal Sandbox API.
This public page demonstrates the policy layer in-browser. The repository contains the Node.js service, local AI planner integration and PayPal Sandbox Orders API path.
