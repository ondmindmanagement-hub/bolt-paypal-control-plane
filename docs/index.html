Architecture
Architecture under evaluation: natural-language intent → local Ollama planner → structured proposed action → deterministic policy review. All current API endpoints are preview-only and do not approve or execute PayPal transactions.
This public page demonstrates the approval-required policy plus fictional order-state comparison. The repository also includes a separate local read-only Sandbox order inspector, which needs credentials and an already-existing test order; it is not called by this website. Actual Sandbox inspection has not been performed or independently verified here. Real payments, order creation from the public API and authenticated approvals are not implemented in this demo.
