BOLT Agentic Payments Control Plane

Governed AI-assisted payment actions with explicit policy gates.

How it works
AI intent → structured action → deterministic policy → human approval when required → PayPal Sandbox execution → audit trail.
The open-source backend includes a PayPal Sandbox OAuth + Orders API connector and an Ollama/Qwen planner. Credentials are supplied at runtime and are never stored in the repository.
